# claude-hackaton

Hackathon project.

## Claude for Compliance

- [`mcp/`](mcp/README.md): the `compliance-knowledge` MCP server (scoping, controls, recipes, checks, hashed evidence).
- `.mcp.json`: lets Claude Code pick the server up from the repo root.
- `sample-repo/`: demo folder with a **fake** API key that the secret check flags.
